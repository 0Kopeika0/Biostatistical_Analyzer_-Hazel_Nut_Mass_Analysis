Название: Биостатистический анализатор — анализ массы орехов лещины / Biostatistical Analyzer — Hazel Nut Mass Analysis

Стек: Python, Tkinter, NumPy, pandas, Matplotlib, SciPy

Что делает: Статистический анализ данных о массе орехов лещины: строит вариационные ряды, считает основные характеристики, проверяет нормальность по критерию Пирсона, строит доверительные интервалы и графики, экспортирует отчёт.
